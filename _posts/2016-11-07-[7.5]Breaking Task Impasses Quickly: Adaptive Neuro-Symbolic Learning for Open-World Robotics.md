# [7.5] Breaking Task Impasses Quickly: Adaptive Neuro-Symbolic Learning for Open-World Robotics

- Authors: Pierrick Lorang
- [arXiv Link](https://arxiv.org/abs/2601.16985v1)
- [PDF Link](https://arxiv.org/pdf/2601.16985v1.pdf)

## Subfields
 规划控制 / 神经符号学习 (Planning & Control / Neuro-Symbolic Learning)
## Reason for Interest

论文针对自动驾驶在开放世界中面临的未知环境变化（Novelties）和任务僵局（Impasses）问题，提出了一种结合分层符号规划与强化学习的神经符号框架。1. **创新性**：通过嵌套动作抽象（Nested Action Abstraction）和好奇心驱动的符号想象（Symbolic Imagination），有效解决了传统混合方法在面对新环境时适应慢、样本效率低的问题，具有较强的理论创新。2. **实验完整性**：在CARLA自动驾驶仿真器中设计了包含天气变化和障碍物的多种长尾场景，对比实验详实，证明了方法在加快适应速度方面的优势。3. **行业价值**：虽然该方法依赖于预定义的符号状态抽象（PDDL-style），在非结构化真实道路环境中的泛化部署存在难度，但为解决自动驾驶的长尾角点案例（Corner Cases）提供了高可解释性和高样本效率的解决思路，属于高质量的学术探索。
