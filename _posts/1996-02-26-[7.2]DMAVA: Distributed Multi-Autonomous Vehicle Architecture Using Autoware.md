# [7.2] DMAVA: Distributed Multi-Autonomous Vehicle Architecture Using Autoware

- Authors: Zubair Islam, Mohamed El-Darieby
- [arXiv Link](https://arxiv.org/abs/2601.16336v1)
- [PDF Link](https://arxiv.org/pdf/2601.16336v1.pdf)

## Subfields
 仿真与测试 / 多车协同仿真架构
## Reason for Interest

该论文提出了一种基于分布式硬件（多台物理主机）运行多辆自动驾驶车辆（Autoware）的仿真架构（DMAVA）。

优点：
1. **工程实用性强**：解决了开源仿真器AWSIM Labs默认仅支持单车仿真的限制，利用Zenoh实现了跨主机的低延迟通信和时间同步，为多车协同（如V2V、多车博弈）研究提供了低成本的验证平台。
2. **开源贡献**：提供了完整的代码和配置，对于使用Autoware生态的研究人员具有较高的参考价值。
3. **实验验证**：在2-3台物理主机上验证了系统的闭环控制、通信延迟（RTT）和资源消耗，证明了方案的可行性。

缺点：
1. **创新性有限**：主要工作在于现有工具（ROS 2, Zenoh, AWSIM, Autoware）的集成与工程适配，而非提出核心的感知或规划算法创新。
2. **规模受限**：实验仅验证了3车场景，对于大规模交通流或更复杂的分布式系统的扩展性验证尚显不足。
3. **依赖性**：方案深度绑定Autoware和AWSIM Labs生态，通用性相对受限。

总体而言，这是一篇扎实的系统架构类论文，对自动驾驶开发工具链有实质性贡献。
