# [7.0] XD-MAP: Cross-Modal Domain Adaptation using Semantic Parametric Mapping

## Subfields
 感知与地图 (Perception & Mapping) / 跨模态域适应 (Cross-Modal Domain Adaptation)
## Reason for Interest

论文提出了一种利用视觉SLAM构建语义参数化地图，进而为LiDAR数据生成伪标签的跨模态域适应方法。创新点在于利用地图作为中介，解耦了源域（相机）和目标域（LiDAR）的时空约束，允许在视场不重叠的情况下进行知识迁移。这对于自动驾驶中静态交通设施（如红绿灯、交通标志、杆状物）的低成本自动标注和高精地图构建具有较高的工程应用价值。然而，该方法存在显著局限性：1. 仅适用于静态刚体目标，无法处理车辆和行人等动态关键要素，限制了其作为通用感知方案的潜力；2. 实验完全依赖私有数据集，且仅对比了简单的内部基线，缺乏与主流开源SOTA方法的横向对比，结果的可复现性和行业普适性存疑。因此给出7.0分，认定其为针对特定工程问题的有效解决方案，而非通用感知领域的重大突破。
