# [3.5] Real-Time Loop Closure Detection in Visual SLAM via NetVLAD and Faiss

- Authors: Enguang Fan
- [arXiv Link](https://arxiv.org/abs/2602.01673v1)
- [PDF Link](https://arxiv.org/pdf/2602.01673v1.pdf)

## Subfields
 Visual SLAM / Loop Closure Detection
## Reason for Interest

1. 实验设计严重不足：仅在 KITTI 的单一序列（Seq 00）上进行评估，无法证明算法的泛化能力，不符合学术标准。
2. 缺乏创新：NetVLAD 是 2016 年提出的算法，结合 Faiss 属于常规工程实现，缺乏算法层面的实质性贡献。
3. 基准对比缺失：仅对比了十年前的 DBoW 算法，忽略了近 8 年来视觉地点识别（VPR）领域的所有进展（如 CosPlace, MixVPR 等更轻量高效的方法）。
4. 时效性差：论文采用的骨干网络和方法在当前自动驾驶研究中已显落后。
