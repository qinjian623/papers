# [4.2] Bandwidth-Efficient Multi-Agent Communication through Information Bottleneck and Vector Quantization

- Authors: Ahmad Farooq, Kamran Iqbal
- [arXiv Link](https://arxiv.org/abs/2602.02035v1)
- [PDF Link](https://arxiv.org/pdf/2602.02035v1.pdf)

## Subfields
 Multi-Agent Reinforcement Learning (MARL) / V2X协同
## Reason for Interest

论文提出了一种结合信息瓶颈（IB）和矢量量化（VQ）的门控通信机制，旨在解决多智能体在有限带宽下的协同问题，理论构建较为扎实，创新性尚可。然而，作为一篇面向自动驾驶/机器人领域的论文，其实验完全依赖于抽象的20x20网格世界（Grid World），缺乏基于真实自动驾驶仿真器（如CARLA、SUMO）或真实数据集的验证。网格世界的离散状态与真实车端的连续动力学、感知噪声和复杂交通场景差距巨大，因此该方法在自动驾驶实际工程中的直接参考价值较低，更多属于通用的MARL算法研究。
