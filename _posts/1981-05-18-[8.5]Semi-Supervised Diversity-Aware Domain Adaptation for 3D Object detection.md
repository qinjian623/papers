# [8.5] Semi-Supervised Diversity-Aware Domain Adaptation for 3D Object detection

- Authors: Bartłomiej Olber, Jakub Winter, Paweł Wawrzyński, Andrii Gamalii, Daniel Górniak, Marcin ...
- [arXiv Link](https://arxiv.org/abs/2512.24922v1)
- [PDF Link](https://arxiv.org/pdf/2512.24922v1.pdf)

## Subfields
 3D感知 / 领域自适应 (LiDAR Domain Adaptation)
## Reason for Interest

论文极具工业落地价值，通过提出基于激活模式的多样性采样策略，证明了极低成本的少样本微调（10帧）可以击败复杂的无监督领域自适应（UDA）方法。这为自动驾驶系统低成本扩展运行设计域（ODD）提供了强有力的工程路径。实验设计严谨，涵盖主流数据集的交叉验证，且对传感器物理特性（线束、扫描方式）的分析非常深入。
