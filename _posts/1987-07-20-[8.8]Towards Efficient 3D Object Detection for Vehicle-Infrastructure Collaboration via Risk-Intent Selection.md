# [8.8] Towards Efficient 3D Object Detection for Vehicle-Infrastructure Collaboration via Risk-Intent Selection

- Authors: Li Wang, Boqi Li, Hang Chen, Xingjian Wu, Yichen Wang, Jiewen Tan, Xinyu Zhang, Huaping L...
- [arXiv Link](https://arxiv.org/abs/2601.03001v1)
- [PDF Link](https://arxiv.org/pdf/2601.03001v1.pdf)

## Subfields
 车路协同感知 (V2I Collaborative Perception) / 3D目标检测
## Reason for Interest

1. 创新性强：论文提出 RiSe 框架，摆脱了传统的基于“置信度”或“压缩”的协同传输范式，转而利用“风险场”和“自车意图”来选择传输区域。这种基于语义关键性（Risk-Intent）的筛选机制非常契合自动驾驶安全本质。
2. 实验效果显著：在极低带宽（0.71%）下不仅保持了精度，还通过过滤背景噪声超越了全量传输基线，建立了新的带宽-精度 Pareto 前沿。
3. 完整性与可信度：在 DeepAccident 安全关键场景数据集上进行了详尽的对比与消融实验，验证了 PTCM（势场轨迹相关模型）和 IDAPM（意图驱动区域预测）的有效性。
4. 行业价值：针对车路协同中最核心的带宽瓶颈问题提供了高可用性的解决方案，且明确针对安全关键目标（如鬼探头、遮挡交互），具有较高的落地潜力。
