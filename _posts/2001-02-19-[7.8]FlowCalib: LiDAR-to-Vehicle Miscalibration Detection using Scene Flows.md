# [7.8] FlowCalib: LiDAR-to-Vehicle Miscalibration Detection using Scene Flows

- Authors: Ilir Tahiraj, Peter Wittal, Markus Lienkamp
- [arXiv Link](https://arxiv.org/abs/2601.23107v1)
- [PDF Link](https://arxiv.org/pdf/2601.23107v1.pdf)

## Subfields
 传感器校准 / 异常检测
## Reason for Interest

1. **创新性与切入点（高）**：论文关注传感器到车体（S2V）的校准，这是一个常被忽略但对安全至关重要（直接影响规划）的领域。利用静态场景流（Scene Flow）的一致性来检测外参漂移，且不依赖IMU/GPS等额外传感器，思路独特且具备物理可解释性。
2. **方法论（中上）**：结合了神经场景流先验（NSFP）与手工几何特征（Global + Geometric features），构建了双分支检测网络。逻辑闭环清晰。
3. **实验与缺陷（中）**：实验基于nuScenes数据集的合成故障注入（Fault Injection），虽然符合校准领域的常规做法，但缺乏真实世界因振动或长期运行导致的非刚性漂移数据。此外，模型在Pitch轴向的检测能力较弱（仅60%左右），限制了其全方位的实用性。
4. **行业价值（高）**：提供了一种轻量级的在线监测方案，有助于提升自动驾驶系统的功能安全（Functional Safety），符合SOTIF标准下的感知监控需求。
