# [4.2] Instance-Guided Radar Depth Estimation for 3D Object Detection

- Authors: Chen-Chou Lo, Patrick Vandewalle
- [arXiv Link](https://arxiv.org/abs/2601.19314v1)
- [PDF Link](https://arxiv.org/pdf/2601.19314v1.pdf)

## Subfields
 3D感知 / 多模态融合 (Camera + Radar)
## Reason for Interest

1. **性能显著落后**：作为一篇arXiv 2026年的论文，其检测性能 (NDS 0.457) 甚至未能超越2023年的CRN (NDS 0.560) 或 CRAFT (NDS 0.517)，且仅在复现的低性能Baseline上展示提升，缺乏即时性价值。
2. **创新边际效应低**：核心贡献‘InstaRadar’利用实例分割扩展雷达点，相比作者之前的JBF方法，在最终检测指标上仅带来极微小的提升 (NDS +0.002)，且引入了OneFormer这种重型预处理模型，计算成本与收益不成正比。
3. **技术路线陈旧**：论文仍坚持‘雷达作为深度图引导’(Radar-as-depth) 的路线，而行业主流已转向更高效的‘BEV特征级融合’。论文承认了架构上的劣势，但未能提出有效的弥补方案。
4. **实验结论矛盾**：文中声称InstaRadar在深度估计上SOTA，但实验数据表显示其RMSE误差反而高于对比方法，仅在定性分析上强调‘语义一致性’，说服力不足。
