# [7.5] DualShield: Safe Model Predictive Diffusion via Reachability Analysis for Interactive Autonomous Driving

- Authors: Rui Yang, Lei Zheng, Ruoyu Yao, Jun Ma
- [arXiv Link](https://arxiv.org/abs/2601.15729v1)
- [PDF Link](https://arxiv.org/pdf/2601.15729v1.pdf)

## Subfields
 规划控制 / 交互式轨迹规划
## Reason for Interest

论文提出了一种结合扩散模型与HJ可达性分析的创新规划框架，有效解决了生成式规划缺乏理论安全保证的问题。方法在理论上具有完备性，仿真实验结果显著优于现有基准。主要扣分点在于验证场景较为单一（仅仿真掉头），且HJ分析的预计算依赖和较高的推理耗时（0.78s）限制了其在复杂动态环境中的实时部署能力和泛化性。
