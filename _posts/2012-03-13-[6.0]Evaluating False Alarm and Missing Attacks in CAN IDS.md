# [6.0] Evaluating False Alarm and Missing Attacks in CAN IDS

- Authors: Nirab Hossain, Pablo Moriano
- [arXiv Link](https://arxiv.org/abs/2602.02781v1)
- [PDF Link](https://arxiv.org/pdf/2602.02781v1.pdf)

## Subfields
 车辆网络安全 / CAN总线入侵检测 (Vehicle Network Security / CAN Bus IDS)
## Reason for Interest

1. **方向定位**：论文关注自动驾驶车辆底层的CAN总线安全，属于自动驾驶系统的关键基础设施安全，符合车端相关性要求。
2. **创新性**：主要贡献在于建立了一个结合‘误报’（False Alarm）和‘漏报’（Missing Attack）的统一评估框架，并施加了符合CAN协议的约束。虽然使用的是现有的攻击方法（FGSM, BIM, PGD），但在该领域的系统性评估具有一定新意。
3. **实验结论**：揭示了深度神经网络（DNN）虽然在良性数据上表现好，但在梯度攻击下极易崩溃；相反，浅层的集成学习模型（如Extra Trees）在对抗环境下更稳健。这一发现对盲目追求深度学习的行业趋势具有警示价值。
4. **局限性**：属于评估类论文，未提出新型防御架构；研究对象为通用的CAN数据，而非针对自动驾驶特有感知/规划数据的攻击，与核心自动驾驶算法距离稍远。
5. **综合评分**：因其扎实的实验（使用ROAD真实数据集）和对工程实践的指导意义，给予及格偏上的分数，但因缺乏核心算法创新，未给高分。
