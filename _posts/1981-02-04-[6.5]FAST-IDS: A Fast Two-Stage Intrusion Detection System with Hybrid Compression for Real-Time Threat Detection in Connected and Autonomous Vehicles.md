# [6.5] FAST-IDS: A Fast Two-Stage Intrusion Detection System with Hybrid Compression for Real-Time Threat Detection in Connected and Autonomous Vehicles

- Authors: Devika S, Vishnu Hari, Pratik Narang, Tejasvi Alladi, Vinay Chamola
- [arXiv Link](https://arxiv.org/abs/2512.24391v1)
- [PDF Link](https://arxiv.org/pdf/2512.24391v1.pdf)

## Subfields
 V2X通信安全 / 车联网入侵检测 (V2X Security / Intrusion Detection)
## Reason for Interest

论文针对网联车（CAV）的资源受限环境，提出了一种基于模型压缩（剪枝+量化）的双阶段入侵检测系统（FAST-IDS）。

优点：
1. **工程价值高**：明确针对车端边缘计算设备（Jetson Nano）进行优化，显著降低了推理延迟，满足自动驾驶对实时性的严苛要求。
2. **架构设计合理**：采用BiGAN处理未知攻击（Zero-day），结合CNN-LSTM处理已知攻击，并通过混合压缩技术平衡了精度与速度。
3. **实验完整**：提供了详细的消融实验和多硬件平台（GPU, CPU, Jetson）对比。

缺点：
1. **数据局限性**：实验完全依赖仿真数据集（VeReMi Extension），缺乏真实世界路测数据的验证，在自动驾驶领域其结果的物理可信度略打折扣。
2. **创新深度**：核心算法组件（BiGAN, CNN-LSTM, 结构化剪枝）均为成熟技术，论文主要贡献在于系统集成与工程优化，缺乏底层理论的突破性创新。
