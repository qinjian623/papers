# [6.2] Mixed Precision PointPillars for Efficient 3D Object Detection with TensorRT

- Authors: Ninnart Fuengfusin, Keisuke Yoneda, Naoki Suganuma
- [arXiv Link](https://arxiv.org/abs/2601.12638v2)
- [PDF Link](https://arxiv.org/pdf/2601.12638v2.pdf)

## Subfields
 3D Object Detection / Edge AI Deployment (Model Quantization)
## Reason for Interest

【创新与价值】该论文提出了一种针对PointPillars的混合精度（INT8+FP16）量化框架，利用贪婪搜索确定敏感层并保留为FP16，有效解决了LiDAR点云数据分布宽和离群值导致的INT8量化掉点问题。通过极少量校准数据来规避离群值的发现具有一定的工程参考价值。

【缺陷与不足】
1. 基准陈旧：论文（设定为2026年）仍主要基于2019年的PointPillars模型和较小的KITTI数据集进行验证，缺乏对nuScenes、Waymo等现代数据集以及BEVFusion、CenterPoint等主流SOTA模型的支持，行业前瞻性不足。
2. 实验局限：主要对比自身基线，未与LIDAR-PTQ、PillarHist等文中提及的竞品进行严格的同条件下量化性能对比。
3. 技术深度：混合精度搜索和敏感度分析是量化领域的通用做法，算法层面的理论创新较弱，更多是针对特定模型的工程调优。
