# [8.8] Mono3DV: Monocular 3D Object Detection with 3D-Aware Bipartite Matching and Variational Query DeNoising

- Authors: Kiet Dang Vu, Trung Thai Tran, Kien Nguyen Do Trung, Duc Dung Nguyen
- [arXiv Link](https://arxiv.org/abs/2601.01036v1)
- [PDF Link](https://arxiv.org/pdf/2601.01036v1.pdf)

## Subfields
 Monocular 3D Object Detection / Perception
## Reason for Interest

该论文针对 DETR 架构在单目 3D 检测中存在的二分图匹配（Bipartite Matching）不匹配问题（即 2D 匹配主导导致 3D 预测被抑制），提出了 3D-Aware Matching 策略和 Variational Query DeNoising 机制。创新点具有较强的针对性和理论依据；实验非常充分，不仅在 KITTI 上取得了 SOTA，还在 Waymo 和 nuScenes 上验证了泛化性；消融实验详尽，证明了各模块的有效性。整体工作扎实，具有较高的学术价值。
