# [4.8] SC-MII: Infrastructure LiDAR-based 3D Object Detection on Edge Devices for Split Computing with Multiple Intermediate Outputs Integration

- Authors: Taisuke Noguchi, Takayuki Nishio, Takuya Azumi
- [arXiv Link](https://arxiv.org/abs/2601.07119v1)
- [PDF Link](https://arxiv.org/pdf/2601.07119v1.pdf)

## Subfields
 路侧感知 (Infrastructure Perception) / V2X / 边缘计算
## Reason for Interest

1. 论文定位偏向系统架构优化（Split Computing），而非核心感知算法创新。主要贡献在于将3D检测网络（Voxel R-CNN）拆分到边缘端和服务器端，以降低路侧单元（RSU）的传输带宽和计算负载。
2. 属于路侧基础设施感知技术，虽然服务于自动驾驶（V2X），但并非直接运行于车端的算法，且使用了现成的检测模型进行工程化改造，算法层面的创新性有限。
3. 实验结果显示该方法在提升效率的同时损失了部分精度（约1% mAP），符合系统级论文的权衡特征，适合网络/系统领域（如CCNC会议），对提升车端核心感知能力的参考价值一般。
