# [3.5] Event-based Heterogeneous Information Processing for Online Vision-based Obstacle Detection and Localization

- Authors: Reza Ahmadvand, Sarah Safura Sharif, Yaser Mike Banad
- [arXiv Link](https://arxiv.org/abs/2601.13451v1)
- [PDF Link](https://arxiv.org/pdf/2601.13451v1.pdf)

## Subfields
 神经形态感知 / 基于事件相机的目标检测
## Reason for Interest

1. **相关性**：论文探讨的‘混合神经网络（ANN+SNN）’及‘事件相机（DVC）’用于低功耗、低延迟感知，在自动驾驶边缘计算领域具有理论价值，符合低能耗硬件的发展趋势。
2. **实验局限**：实验极为简陋。仅使用了一个‘旋转圆盘上的三个几何形状’的仿真视频作为验证，属于Toy Example级别。缺乏真实的道路场景、复杂的交通参与者以及光照变化等自动驾驶核心挑战的测试。
3. **成熟度**：文章篇幅较短，更接近于早期的概念验证（Proof of Concept）。提出的SNN滤波器虽然理论上有抗噪优势，但未通过对比实验证明其优于传统的卡尔曼滤波或基于Transformer的SOTA方法。
4. **综合评价**：属于学术界的探索性工作，距离车端自动驾驶的实际应用非常遥远，作为参考的工程价值较低，因此评分受限。
