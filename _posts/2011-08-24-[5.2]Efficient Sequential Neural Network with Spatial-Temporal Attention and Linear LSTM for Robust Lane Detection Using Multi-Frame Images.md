# [5.2] Efficient Sequential Neural Network with Spatial-Temporal Attention and Linear LSTM for Robust Lane Detection Using Multi-Frame Images

- Authors: Sandeep Patil, Yongqi Dong, Haneen Farah, Hans Hellendoorn
- [arXiv Link](https://arxiv.org/abs/2602.03669v1)
- [PDF Link](https://arxiv.org/pdf/2602.03669v1.pdf)

## Subfields
 感知 / 车道线检测 (Perception / Lane Detection)
## Reason for Interest

该论文提出了一种结合时空注意力机制和Linear LSTM的序列化车道线检测方法，旨在利用多帧时序信息解决遮挡和光照问题。虽然研究动机合理且消融实验详细，但存在以下严重问题导致评分较低：
1. 实验基准过时：主要对比的是2018-2020年间的分割模型（如SCNN, LaneNet, SegNet）及其LSTM变体，忽略了近年来性能更优的基于Anchor、Row-wise分类或Transformer的SOTA方法（如CLRNet, CondLaneNet等）。
2. 结果缺乏竞争力：在LLAMAS数据集上，核心指标AP比之前的相关工作低了约14个百分点，论文对此解释为“高精度偏好”缺乏说服力。
3. 架构老旧：采用基于UNet的逐像素分割方案，在当前车道线检测领域通常不如结构化建模方法高效（尽管论文声称低MACs，但44G MACs相比现代轻量级检测器仍然较高）。
