# [6.0] Cross-Layer Attentive Feature Upsampling for Low-latency Semantic Segmentation

- Authors: Tianheng Cheng, Xinggang Wang, Junchao Liao, Wenyu Liu
- [arXiv Link](https://arxiv.org/abs/2601.01167v1)
- [PDF Link](https://arxiv.org/pdf/2601.01167v1.pdf)

## Subfields
 感知 / 2D语义分割 (Perception / 2D Semantic Segmentation)
## Reason for Interest

1. **细分方向**：论文专注于自动驾驶场景下的低延迟（实时）2D语义分割，属于车端感知的基础任务，符合自动驾驶领域要求。
2. **创新性**：提出了引导注意力插值（GAI）模块，利用高分辨率特征作为 Query，低分辨率特征作为 Key/Value 进行上采样，解决了传统双线性插值的语义不对齐问题。方法逻辑合理，但属于组件级改进，非架构级突破。
3. **SOTA 声明存疑**：尽管论文声称 SOTA，但其正文 Table 1 数据显示，对比方法 RDRNet (参考文献 [72], 2024年) 在 Cityscapes 上的 mIoU (78.9%) 和 FPS (24.2) 均优于本文方法 GAIN (78.8%, 22.3 FPS)。在 CamVid 数据集上，文中强调的 80.6 mIoU 是基于 Cityscapes 预训练的结果，而从头训练的结果 (74.6 mIoU) 明显低于 RDRNet (78.4 mIoU)。
4. **综合评价**：作为一篇标记为 2026 年的论文，未能显著超越 2024 年的基线（RDRNet），且在核心指标上存在劣势，其实际行业价值和技术领先性受到削弱。虽然方法对实时性优化有一定参考意义，但评分因 SOTA 声明与数据的不一致而扣减。
