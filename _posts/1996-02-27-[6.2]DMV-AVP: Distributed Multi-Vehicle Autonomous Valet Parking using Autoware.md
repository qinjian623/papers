# [6.2] DMV-AVP: Distributed Multi-Vehicle Autonomous Valet Parking using Autoware

- Authors: Zubair Islam, Mohamed El-Darieby
- [arXiv Link](https://arxiv.org/abs/2601.16327v1)
- [PDF Link](https://arxiv.org/pdf/2601.16327v1.pdf)

## Subfields
 自动驾驶仿真 / 自主代客泊车 (Simulation / AVP)
## Reason for Interest

论文提出了一个基于Autoware Universe和Zenoh的分布式多车自动泊车（AVP）仿真框架。主要贡献在于系统架构的工程集成，验证了跨主机通信和多车协同的可行性，且代码开源，对社区有一定参考价值。然而，论文在算法创新上较为薄弱：1. 感知模块仅使用基础YOLOv5且泛化能力差（文中承认仅对红色轿车检测效果好）；2. 规划控制依赖Autoware原生模块，且在取车（Retrieval）环节因规划器限制导致失败，需人工干预；3. 实验规模较小（仅3车）。属于工程实现类工作，缺乏显著的理论或算法突破。
