# [7.9] Efficient Visual Question Answering Pipeline for Autonomous Driving via Scene Region Compression

- Authors: Yuliang Cai, Dongqiangzi Ye, Zitian Chen, Chongruo Wu
- [arXiv Link](https://arxiv.org/abs/2601.07092v1)
- [PDF Link](https://arxiv.org/pdf/2601.07092v1.pdf)

## Subfields
 自动驾驶大模型 / 视频问答 (AD VLM / VideoQA)
## Reason for Interest

该论文针对自动驾驶场景下VLM推理的高延迟问题，提出了一种基于场景区域压缩（Scene Region Compression）的高效Pipeline。核心创新在于利用AD场景的时序特性，将早期历史帧压缩为少量的高层语义Token（全图+4个区域），仅保留最新帧的Patch Token。这种设计在大幅降低计算量（FLOPs减少66%）的同时，较好地保留了上下文信息，性能损失很小（相比Dense输入仅下降约0.9分）。虽然绝对精度未达SOTA，但其针对车端算力受限场景的工程价值极高，来自USC和XPeng的研究背景也增加了其实用性的可信度。缺点是仅在LingoQA单一数据集上验证，缺乏闭环驾驶或真车延迟测试数据。
