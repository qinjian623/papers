# [7.2] Learning Contextual Runtime Monitors for Safe AI-Based Autonomy

- Authors: Alejandro Luque-Cerpa, Mengyuan Wang, Emil Carlsson, Sanjit A. Seshia, Devdatt Dubhashi, ...
- [arXiv Link](https://arxiv.org/abs/2601.20666v1)
- [PDF Link](https://arxiv.org/pdf/2601.20666v1.pdf)

## Subfields
 自动驾驶安全 / 运行时监控 (Safety / Runtime Monitoring)
## Reason for Interest

该论文提出了一种基于上下文多臂老虎机（Contextual Bandits）的运行时监控框架，用于管理基于AI的控制算法集成。主要优点在于：1. 理论扎实，提供了监控器选择的安全性和后悔值（Regret）的理论界限；2. 针对黑盒模型在不同运行域（OD）下的性能差异问题提出了有效的动态切换机制；3. 在CARLA仿真器中进行了验证。扣分点主要在于：1. 实验完全依赖定制的仿真场景（SCENIC生成），缺乏在nuScenes、Waymo等主流真实数据集或CARLA Leaderboard标准基准上的验证；2. 方法主要聚焦于控制器的集成策略，而非直接提升感知或控制算法本身的SOTA性能；3. 场景较为受限（车道保持和简单的避障），距离复杂的真实城市道路部署仍有差距。
